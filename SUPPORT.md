# Support

doc-tools has community support on a best-effort basis.

## Where to ask

- Use GitHub issues for bugs, documentation problems, and feature requests.
- For security problems, do not open a public issue. See [SECURITY.md](SECURITY.md).

## What to include

- the doc-tools version or commit
- the operating system and architecture
- the command that you used
- the expected result
- the actual result and the error output
