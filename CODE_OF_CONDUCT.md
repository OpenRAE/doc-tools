# Code of conduct

## Expected behavior

Keep discussion technical, concrete, and respectful.
Disagreement in good faith about design, security, and documentation is welcome.

- Criticize ideas, code, and evidence, not people.
- Give enough context for others to understand a concern.
- Accept that maintainers can reject changes that do not fit the project.
- Do not use personal attacks, harassment, or discriminatory language.
- Do not publish private information without permission.

## Scope

This code applies to issues, pull requests, discussions, and other repository work.

## Reporting

Report conduct problems privately to the maintainer.
Use the contact path on the [Brad Edwards GitHub profile](https://github.com/Brad-Edwards).

The maintainer can remove comments, close threads, decline contributions, or block participants.
